# 답변 스트리밍 애니메이션

DesignBookmark Motion Studies의 "Streaming reply"를 React로 옮겼다. 원본은 의존성 없는 HTML·CSS·JS다.

- 원본: `motion-src/streaming-reply/` (`stream.css`, `stream.js`), 공용 `motion-src/shared/` (`tokens.css`, `base.css`, `motion.js`)
- 구현: `src/agent/bubbles.tsx`, `src/motion/spring.ts`, 스타일은 `src/index.css`의 `.stream-*`

## 움직임

1. 질문 말풍선이 14px 아래에서 0.92배 크기로 떠오른다.
2. 답 말풍선이 "생각 중" 알약으로 열린다. 글자에는 빛이 지나가는 효과가 있다.
3. 단어가 도착하면 하나씩(0.07초 간격) 6px 아래에서 떠오르며 흐림(4px)이 걷힌다.
4. 말풍선의 너비·높이는 스프링으로 늘어나 단어를 담는다. 글은 최종 너비로 미리 줄을 맞춰 두므로 줄이 다시 바뀌지 않는다.
5. 다 들어오고 멈추면 고정 크기를 풀어 일반 레이아웃으로 돌린다.

## 스프링 값 (강성 · 감쇠)

원본 `stream.js`와 같은 값이다.

| 대상 | 값 |
|---|---|
| 말풍선 등장 (질문·답) | 300 · 22 |
| 말풍선 너비·높이 | 260 · 26 |
| "생각 중" 투명도 | 300 · 30 |
| 단어 하나 | 340 · 26 |

엔진도 원본 `motion.js`와 같다: 프레임마다 dt를 1/30초로 자르고 4번 나눠 계산한다. 움직임 줄이기 설정이면 감쇠를 임계값(2√k)으로 바꾼다.

## 원본과 다른 점

- 원본은 말풍선을 항상 최대 너비로 펼친다. 여기서는 **필요한 만큼만** 넓어진다.
- 원본은 rAF를 계속 돌린다. 여기서는 **움직이는 것이 있을 때만** 돈다.
- "생각 중"을 최소 0.6초 보여 준 뒤 단어를 내보낸다 (답이 너무 빨리 와도 깜빡이지 않게).
- 화면 읽기 프로그램은 다 받은 뒤 문장을 한 번 읽는다.
- 색·글꼴·모서리는 이 프로젝트의 디자인 토큰(`src/index.css`의 `:root`)을 쓴다. 모서리는 거의 직각(3px)이다.
- 말풍선 안쪽 여백(13px·9px)은 `bubbles.tsx`의 `PAD_X`·`PAD_Y`, CSS의 `.bubble` 패딩·`.stream-text` 위치와 같아야 한다.
- 패널을 다시 열 때 지난 대화는 움직이지 않는다.

## 알아 둘 점

- 창이 뒤에 있으면 브라우저가 프레임을 늦춰 단어가 천천히 나온다 (원본도 같다).
- "생각 중" 자리표시와 실제 답 말풍선은 같은 key(바로 앞 메시지 기준)를 써서, 답이 도착해도 새로 만들어지지 않고 이어서 자란다.
