# 휴가·근태

휴가 신청(전자결재 상신까지), 연차 현황, 이번 주 근무시간을 다룹니다.

## 흐름

```
"금요일 연차 쓸게"
  → leave_request       종류(연차·오전 반차·오후 반차), 잔여 연차(신청 후), 대결자, 그날 팀 부재, 그날 내 일정 수, 결재선
                        [상신] → [상신 확정]  (카드 안에서 한 번 더 확인)
  → 휴가 기록 (결재 중) + 전자결재 "휴가신청" 상신 → STATE_DELTA로 leave.submitted 추가
  → show_leave_result   문서 번호, 결재자, 대결자, 남은 연차 (보여 주기만)

"연차 몇 개 남았어?"   → show_leave_status   연차 막대, 내 휴가 예정, 앞으로 2주 팀 부재
"이번 주 근무시간"     → show_attendance     월~오늘 출퇴근, 주 40시간 눈금 / 52시간 막대
```

상신한 휴가는 결재함의 "내가 올린 문서"에 금액 대신 일수로 나온다.

## 요청 해석 (모의)

| 항목 | 표현 | 비고 |
|---|---|---|
| 종류 | 연차·휴가 / 오전 반차·오전만 / 오후 반차·오후만 | "반차"만 말하면 오후로 잡고 알려 준다 |
| 날짜 | "금요일", "다음 주 월요일", 내일·모레, "11월 26일", "26~27일", "26일부터 30일까지" | 주말은 빠진다. 없으면 카드 없이 날짜를 묻는다 |
| 여러 날 | | 반차는 하루만 되므로 연차로 바꾸고 알려 준다 |

- "휴가신청 문서만 보여줘"처럼 **문서·결재**를 말하면 전자결재 영역이 맡는다 (결재함 필터).
- 확인: 주말·지난 날짜·이미 낸 날·남은 연차 초과는 상신하지 않는다.

## 복셀 연동

신청서는 넓은 패널에서 쓰고 복셀은 줌 아웃한 채로 둔다. 대신 **신청한 첫날의 사무실을 미리 보여 준다**:
그날 부재 예정인 팀원 캐릭터를 부재로 바꾸고, 장면 위에 "11월 20일 (금) 사무실 미리보기 · 부재 2명"을 띄운다
(`SceneHint.away`, `SceneHint.note`). 카드에 답하면 원래 재실 상태로 돌아간다.

## 다루지 않는 정보

- **휴가 사유는 받지 않는다.** 신청서에 사유 칸이 없다. "병원 가야 해서"처럼 건강 관련 사유를 말하면
  기록하지 않고 연차로만 올린다고 안내한다 (건강 정보는 금지 등급).
- 다른 사람의 휴가는 **이름과 부재(연차·오전·오후)만** 보여 준다.
- 근태는 **내 기록만** 다룬다. 다른 사람의 출퇴근·근무시간은 보여 주지 않는다.
- 연차 일수·근무시간은 가상 값이다.

## 가상 데이터

- 연차: 올해 15일, 사용 8.5일.
- 대결자 후보: 플랫폼팀 수석·책임 (단비, 마루, 가온, 바다). 그날 부재면 고를 수 없다.
- 결재선: 기안(나) → 결재(가람 본부장).
- 팀 부재 예정: 11/20 마루(연차)·도담(오전), 11/23 다솜, 11/24 단비(오후), 11/27 가온·바다(오전), 12/1 새벽.
