# 사람·조직 찾기

담당 업무·이름·팀으로 사람을 찾고, 사무실(복셀)에 자리가 있으면 그 자리를 비춥니다.

## 흐름

```
"보안 점검 담당자 누구야?"      → show_people   맞은 담당 업무를 강조한 사람 카드 (최대 3명)
"마루 수석 자리 어디야?"         → show_people   이름으로 찾기 + 지금 재실 상태
"디자인팀 누구 있어?", "조직도"  → show_org      팀별 구성원 (이름·직급·대표 담당 업무·재실)
```

모두 보여 주기만 하는 카드다. 사람 카드에는 팀·근무 위치, 담당 업무, 내선, 업무 메일, 재실이 나온다.
일정을 잡으려면 이어서 "단비님이랑 회의 잡아줘"처럼 말하면 일정 조율이 맡는다.

## 요청 해석 (모의)

| 종류 | 알아보는 말 |
|---|---|
| 이름 | 조직도에 있는 이름 + 연락처·내선·메일·자리·어디·누구·소속 등 (낱말 안에 든 이름은 무시) |
| 팀 | 팀 이름 + 누구·구성·팀원·명단, 또는 "조직도" |
| 담당 업무 | "담당자", "누구한테", "문의" 등. 사람마다 둔 찾기 낱말(보안, VPN, 노트북, 계정, 로고 …)과 맞춰 점수를 매긴다 |

- "한결님이랑 회의 잡아줘"처럼 회의를 잡는 말은 일정 조율이 맡는다 (사람 찾기 0점).
- 못 찾으면 카드 없이 예시를 들어 다시 묻는다.

## 복셀 연동

| 찾은 사람 | 패널 | 복셀 |
|---|---|---|
| 3층 플랫폼팀 (복셀에 자리 있음) | 좁게 | 그 자리로 카메라 이동, 이름표를 강조색으로 |
| 다른 층 팀 | 넓게 | 전체 줌 아웃 |
| 조직도 | 넓게 | 나온 사람 중 사무실에 있는 사람의 이름표만 강조 |

- 공유 상태 `people.focusIds`(자리가 있는 사람)로 레이아웃을 정한다 (`DomainUI.spatial`).
- 엔진의 초점 함수가 회의실 id뿐 아니라 구성원 id도 받는다 (자리 주변 40복셀 범위).
- `SceneHint.people`로 이름표를 강조한다.

## 다루는 정보

- **업무 연락처 수준만** 둔다: 이름, 팀, 직급, 담당 업무, 내선, 업무 메일, 근무 위치. 개인 연락처·주소·생년월일 같은 정보는 없다.
- 재실은 근무 중·회의 중·부재만 보여 준다. 오늘 연차인 사람은 사유 없이 "부재"다.
- 메일 주소는 예시용 도메인(`example.com`)을 쓴다. 모든 인물은 가상이다.
- 플랫폼팀의 재실은 화면의 가상 재실 구독 값을 백엔드에 넘겨 쓴다 (실제로는 에이전트 서버가 재실 API를 부른다).
