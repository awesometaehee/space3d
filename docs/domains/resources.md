# 자원 예약

법인차, 대여 장비(빔프로젝터·노트북·화상회의 키트), 자율 좌석을 오전·오후·종일 단위로 예약합니다.

## 흐름

```
"내일 법인차 쓸 수 있어?", "금요일 오후 빔프로젝터 빌려줘", "내일 자율석 예약해줘"
  → pick_resource          그날 자원 목록 + 자원마다 [오전] [오후] [종일] (예약된 시간대는 취소선, 말한 시간대는 테두리)
  → confirm_resource       용도(차량은 행선지, 선택) + 쓸 때 알아 둘 점   [다시 고르기] [취소] [예약하기]
  → 예약 (백엔드) → STATE_DELTA로 resources.reservations 추가
  → show_resource_result   완료 카드 (보여 주기만)

"내 예약 현황"             → show_my_reservations
```

## 요청 해석 (모의)

| 항목 | 표현 | 기본값 |
|---|---|---|
| 종류 | 법인차·업무차·차량·"차 쓸 수 있어?" / 빔프로젝터·대여 노트북·화상회의 키트 / 자율석·공용 좌석·"자리 예약" | – |
| 날짜 | 오늘·내일·모레, 요일, "다음 주 화요일", "11월 20일" | 오늘 (답변에서 알려 준다) |
| 시간대 | 오전 / 오후 / 종일·하루 | 카드에서 고른다 |
| 품목 | 프로젝터 / 노트북 / 화상회의·카메라 | 장비 전체 |

- "차례", "차이"처럼 "차"가 들어간 다른 말은 자원 예약으로 보지 않는다.
- "노트북 신청은 누구한테 해?"는 사람 찾기가 맡는다 (담당자 문의).
- 종일 예약은 오전·오후를 모두 막는다. 오늘 오후 1시가 지나면 오늘 오전·종일은 고를 수 없다.

## 복셀 연동

사무실 업무 공간에서 주인이 없던 책상 4곳을 **자율석 1~4**로 쓴다 (`HOT_DESK_ZONES`, 책상 높이로 덮는다).

| 종류 | 패널 | 복셀 |
|---|---|---|
| 자율 좌석 | 좁게 | 쓸 수 있는 자리 강조·확대. **3D에서 자리를 눌러 바로 고른다** (말한 시간대, 없으면 되는 가장 긴 시간대) |
| 법인차·장비 | 넓게 | 전체 줌 아웃 |
| 예약한 자율 좌석 | – | 초록 강조 + "자율석 2 · 11/19 오전 예약" 이름표 |

- 3D 선택 응답은 영역마다 다르므로 `SceneHint.pick(id)`로 정한다 (없으면 회의실처럼 `{ roomId }`).
- 카드에서 자율석 줄에 마우스를 올리면 3D의 자리가 진해진다.

## 다루는 정보

- 예약에는 자원, 날짜, 시간대, 용도(선택, 60자)만 남긴다.
- 차량 번호, 운전면허, 결제 정보는 다루지 않는다.
- 모든 자원과 기존 예약은 가상 데이터다.
