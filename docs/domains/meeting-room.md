# 회의실 예약

## 흐름

```
"내일 오후 4명 회의실 잡아줘"
  → show_room_options    회의실 후보 (인원 초과·빈 시간 없음은 비활성)
  → show_time_slots      선택한 방의 시간 (예약된 시간은 취소선)  [다른 회의실] [취소]
  → confirm_booking      제목 수정 후 [예약하기] [취소]
  → 예약 (백엔드) → STATE_DELTA로 bookings 추가
  → show_booking_result  완료 카드 (보여 주기만)
```

## 요청 해석 (모의)

| 항목 | 표현 | 기본값 |
|---|---|---|
| 날짜 | 오늘·내일·모레, "11월 20일", "20일" (지난 날짜는 다음 달·내년) | 오늘 |
| 시간대 | 오전·아침 / 오후·저녁 | 하루 전체 |
| 인원 | "4명", "6인" | 4명 |
| 길이 | "1시간 반", "30분" (30분 단위, 30분~4시간) | 1시간 |

기본값을 쓴 항목은 답변에서 알려 준다.

## 복셀 연동

- 후보 회의실: 파란 강조, 이름표, 카메라 이동. 3D에서 방을 눌러도 선택된다.
- 카드에서 방에 마우스를 올리면 3D의 방이 진해진다.
- 예약한 방: 초록 강조 + "11/19 16:30 예약" 이름표.
- 패널이 열려 있으면 패널 폭만큼 비켜서 초점을 맞춘다.

`src/data/meetingRooms.ts`

|---|---|---|
| 회의실 A | 6 | 화이트보드, 빔프로젝터 |
| 회의실 B | 4 | TV 화면 공유 |

운영 시간 9~18시, 점심(12~13시) 제외. 기존 예약은 날짜·방마다 항상 같게 만들어지는 가상 예약이다.
